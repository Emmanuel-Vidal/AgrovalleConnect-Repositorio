
# Especificación de Requisitos de Software (IEEE 29148)

**Proyecto:** AgroValle Connect
**Módulo:** Gestión de Registro y Búsqueda Geográfica
**Redacción:** Tercera Persona (Estándar Académico UniAJC)

---

## 1. Requisito Funcional: HU-01 - Registro de Agricultores

* **Identificador:** REQ-FUN-001
* **Nombre:** Registro Inicial de Productores Agrícolas
* **Descripción:** El sistema debe permitir la creación de cuentas de usuario con rol de agricultor previa validación del número de cédula y residencia dentro del departamento del Valle del Cauca.
* **Criterio de Validación:** La API procesará solicitudes HTTP POST enviando una respuesta estructurada en formato JSON con código de estado `201 Created` al verificar la unicidad del documento.

## 2. Requisito Funcional: HU-04 - Búsqueda por Municipio

* **Identificador:** REQ-FUN-004
* **Nombre:** Filtrado Geográfico de Cosechas Disponibles
* **Descripción:** El sistema debe realizar la búsqueda y filtrado dinámico de publicaciones activas utilizando como parámetro principal el municipio de origen de la finca.
* **Criterio de Validación:** La API responderá peticiones GET filtradas por la variable `municipio` retornando un arreglo de publicaciones disponibles asociadas a dicha zona geográfica con código HTTP `200 OK`.
