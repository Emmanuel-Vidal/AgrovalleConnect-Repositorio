# Mockups y Especificación de Interfaz de Usuario (UI) — AgroValle Connect

Descripción de las pantallas principales contempladas para la experiencia de usuario en la plataforma:

1. **Pantalla de Autenticación y Registro (`/auth/login` y `/auth/register`):**
   * Selector dinámico de roles (Agricultor, Comprador, Transportista), validación estricta de Cédula única, correo y contraseña cifrada.

2. **Dashboard del Agricultor (`/dashboard/agricultor`):**
   * Panel de control con métricas de cosechas, tabla de productos activos y botón de acción rápida para *"Publicar Nueva Cosecha"* (cultivo, cantidad en kg, precio y municipio).

3. **Catálogo Agrícola para Compradores (`/comprador/catalogo`):**
   * Barra de filtrado geográfico por municipios del Valle del Cauca (Cali, Palmira, Tuluá, Buga, Jamundí) y tarjetas con información detallada de cosechas disponibles.

4. **Módulo de Logística y Fletes (`/transportista/fletes`):**
   * Listado de órdenes de compra pendientes de transporte para que los transportistas seleccionen y acepten rutas de carga de manera eficiente.
