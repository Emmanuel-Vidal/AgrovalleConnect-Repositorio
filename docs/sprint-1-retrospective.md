
# Sprint 1 Retrospective — AgroValle Connect

## ¿Qué salió bien?

- Se implementó correctamente la arquitectura MVC.
- Se configuró la persistencia con MySQL y Spring Data JPA.
- Se construyeron los módulos principales de usuarios y productos.
- Se mantuvo una estructura organizada del proyecto.
- La comunicación del equipo permitió completar las historias priorizadas.

---

## ¿Qué pudo mejorar?

- La división de tareas pudo ser más detallada desde el inicio.
- Faltó una mejor gestión de ramas y revisiones de código.
- Algunas actividades de documentación se realizaron al final del sprint.

---

## ¿Qué acciones tomaremos?

- Utilizar ramas de desarrollo para nuevas funcionalidades.
- Mantener actualizada la documentación durante el sprint.
- Descomponer las historias de usuario en tareas técnicas más pequeñas.
- Registrar reuniones y avances mediante bitácoras Scrum.

---

## Conclusión

El Sprint 1 permitió construir la base técnica del proyecto AgroValle Connect y dejó preparada la estructura necesaria para continuar con la implementación de nuevas funcionalidades y actividades de calidad en iteraciones posteriores.
