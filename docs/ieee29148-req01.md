
# Especificación de Requisitos IEEE 29148 — AgroValle Connect

Este documento establece la especificación formal de los requerimientos de software para el proyecto **AgroValle Connect**, siguiendo los lineamientos del estándar internacional **IEEE 29148** para la ingeniería de requerimientos.

---

## 1. Introducción y Propósito

AgroValle Connect es una plataforma tecnológica diseñada para optimizar la cadena de comercialización agrícola en el Departamento del Valle del Cauca, conectando directamente a agricultores, compradores y transportistas mediante un ecosistema digital robusto en Java 17 y Spring Boot.

## 2. Requisitos Funcionales (RF)

* **RF-01 (Registro y Autenticación):** El sistema debe permitir el registro de usuarios especificando su rol (*Agricultor*, *Comprador*, *Transportista*, *Administrador*) y validando la unicidad de la cédula.
* **RF-02 (Gestión de Cosechas):** El agricultor autenticado debe poder publicar ofertas de productos indicando tipo de cultivo, cantidad en kilogramos, precio por unidad y fecha de cosecha.
* **RF-03 (Filtrado Geográfico):** El sistema debe permitir a los compradores buscar y filtrar productos agrícolas según el municipio de origen en el Valle del Cauca.
* **RF-04 (Coordinación Logística):** El sistema debe calcular y asignar solicitudes de transporte para las órdenes de compra confirmadas, vinculando a un transportista disponible.
* **RF-05 (Sistema de Calificación):** El comprador debe poder calificar la transacción comercial con una puntuación de 1 a 5 estrellas y un comentario para actualizar la reputación del agricultor.

## 3. Requisitos No Funcionales (RNF)

* **RNF-01 (Rendimiento):** El tiempo de respuesta promedio de las consultas al catálogo de productos no debe superar los 2 segundos bajo condiciones normales de tráfico.
* **RNF-02 (Seguridad):** Las comunicaciones y credenciales de acceso deben protegerse mediante mecanismos de autenticación basados en tokens (JWT) y encriptación de contraseñas.
* **RNF-03 (Disponibilidad y Stack):** El backend debe estar desarrollado bajo el framework Spring Boot (Java 17) y persistir la información en una base de datos relacional MySQL, garantizando alta cohesión y bajo acoplamiento.
