---

### Recursos Claves

- Infraestructura Backend en Java/Spring Boot.
- Base de Datos MySQL relacional.
- Integración de API de pagos (Nequi/PSE).

### Canales

- Aplicación Web Progresiva (PWA).
- Notificaciones vía correo y SMS.

---

### Estructura de Costos

- Mantenimiento y hosting de infraestructura en la nube.
- Comisiones por pasarelas de pago electrónico.
- Campañas de soporte y marketing local.

### Fuentes de Ingresos

- Comisión por transacción completada exitosamente (porcentaje sobre la venta).
- Tarifas preferenciales para publicaciones destacadas de cosechas.
